# Against a real game, not another bot: drops an item next to the player, carries it the way a hand does, puts it
# down, moves it once more in one go, and picks it up. At each CHECK Tools\VR\live-check.py reads the placed item's
# position out of the game. Written 2026-10-01 for the first run with nobody in the headset.
#
#   python Tools\VR\live-check.py live-dropmove
log live dropmove
waitfor connected 45

# sends that roll here, so this bot's idea of where the item lies ends up where it came to rest.

log CHECK drop mark
wait 3

# Handed back to physics two seconds after the last word, it stays where it is until something touches it (found
# 2026-10-01). Asked again after that moment, so a change in that behaviour shows up here.
