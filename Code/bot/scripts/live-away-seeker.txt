# told the client so. The client took every temporary remote actor for a copy it had made, and disabled this one
# in the middle of the game's disposal; 25 ms later the game's movement code ran on it and crashed
# (SkyrimVR.exe+0x714EB2, the Seeker in R15, marked deleted by the game).
#
